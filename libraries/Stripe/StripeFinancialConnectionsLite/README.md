# SwiftBindings.Stripe.FinancialConnectionsLite

Transitive support package for the [Stripe iOS SDK](https://github.com/stripe/stripe-ios) bindings. Wraps `StripeFinancialConnectionsLite.xcframework` — the lightweight bank-payment flow that `StripePaymentSheet` links against from Stripe 26.7.0 onward.

> 📖 **[Full usage guide →](https://github.com/justinwojo/swift-dotnet-packages/wiki/Stripe)** — where the Financial Connections packages sit in the Stripe package map.

> **You should not install this package directly.** It is pulled in automatically as a transitive dependency by `SwiftBindings.Stripe.PaymentSheet`. It exists as a standalone NuGet only so its binary can be shared across siblings without duplication.

This package exposes **no managed API**. `StripeFinancialConnectionsLite` publishes no public Swift symbols, so there is nothing to bind; the package ships the framework binary alone. `StripePaymentSheet` carries a hard load-time dependency on it, so an app that embeds PaymentSheet without this framework fails at launch with a `Library not loaded` dyld error.

Distinct from [`SwiftBindings.Stripe.FinancialConnections`](https://www.nuget.org/packages/SwiftBindings.Stripe.FinancialConnections), which is the full Financial Connections SDK with its own binding surface.

These bindings are auto-generated by [Swift Dotnet Bindings](https://github.com/justinwojo/swift-dotnet-bindings) using .NET 10's native Swift interop via the [SwiftBindings SDK](https://www.nuget.org/packages/SwiftBindings.Sdk).
