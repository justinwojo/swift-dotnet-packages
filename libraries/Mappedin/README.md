# SwiftBindings.Mappedin

Native Swift interop bindings for [Mappedin](https://www.mappedin.com/), the indoor mapping and wayfinding SDK. These are not Objective-C proxy wrappers — they use .NET 10's native Swift interop for direct, high-performance calls into Swift APIs from C#.

> 📖 **[Full usage guide →](https://github.com/justinwojo/swift-dotnet-packages/wiki/Mappedin)** — loading map data with Mappedin credentials, displaying the map view, markers, labels, camera, search, wayfinding, and Blue Dot.

## Installation

```
dotnet add package SwiftBindings.Mappedin
```

## Requirements

- .NET 10.0+
- iOS 15.0+
- macOS host for development
- A Mappedin developer account and API credentials for live data

## Usage

### Display a map

```csharp
using Mappedin;
using Swift;
using UIKit;

var mapView = new MapView();

// mapView.View is a MapViewController, which derives from WebKit.WKWebView
var webView = mapView.View;
webView.Frame = View.Bounds;
View.AddSubview(webView);

using var options = new GetMapDataWithCredentialsOptions(
    key: "mik_…",
    secret: "mis_…",
    mapId: "your-map-id");

mapView.GetMapData(options, result =>
{
    if (!result.IsSuccess) return;

    using var show = new Show3DMapOptions();
    mapView.Show3dMap(show, _ => { /* map rendered */ });
});
```

### Coordinates and camera

```csharp
using var here = mapView.CreateCoordinate(43.6532, -79.3832, floorId: "floor-1");

mapView.Camera.FocusOn(here, _ => { });

using var target = new CameraTarget(bearing: 90, pitch: 45, zoomLevel: 19);
mapView.Camera.AnimateTo(target, _ => { });
```

See the [usage guide](https://github.com/justinwojo/swift-dotnet-packages/wiki/Mappedin) for markers, labels, events, search, wayfinding and Blue Dot.

## Caveats

The Mappedin xcframework is licensed by Mappedin and not open source — it must be provisioned out-of-band. The NuGet package ships the binding metadata; consumers must obtain the Mappedin SDK directly from Mappedin and follow their licensing terms.

## How It Works

These bindings are auto-generated by [Swift Dotnet Bindings](https://github.com/justinwojo/swift-dotnet-bindings) using .NET 10's native Swift interop via the [SwiftBindings SDK](https://www.nuget.org/packages/SwiftBindings.Sdk).
