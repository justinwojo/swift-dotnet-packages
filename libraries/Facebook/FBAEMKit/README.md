# SwiftBindings.Facebook.AEM

.NET bindings for **FBAEMKit** (Aggregated Event Measurement) from the
[Facebook iOS SDK](https://github.com/facebook/facebook-ios-sdk). A dependency of
`SwiftBindings.Facebook.Core`.

Built from the official prebuilt `FBAEMKit.xcframework` (dynamic) at upstream v18.1.0.

Targets .NET 10 on iOS.
