# SwiftBindings.Facebook.Share

.NET bindings for **FBSDKShareKit** from the
[Facebook iOS SDK](https://github.com/facebook/facebook-ios-sdk). Provides Facebook sharing:
`ShareLinkContent`, `ShareDialog`, `SharePhotoContent`, `ShareVideoContent`, `Hashtag`,
`MessageDialog`, and share buttons.

> 📖 **[Full usage guide →](https://github.com/justinwojo/swift-dotnet-packages/wiki/Facebook)** — building share content, presenting `ShareDialog`/`MessageDialog`, handling results via `ISharingDelegate`, and the two `ShareDialog` members that are not callable.

Depends on `SwiftBindings.Facebook.Core`.

Built from the official prebuilt `FBSDKShareKit.xcframework` (dynamic) at upstream v18.1.0.

Targets .NET 10 on iOS.
