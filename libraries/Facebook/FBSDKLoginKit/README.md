# SwiftBindings.Facebook.Login

.NET bindings for **FBSDKLoginKit** from the
[Facebook iOS SDK](https://github.com/facebook/facebook-ios-sdk). Provides Facebook Login:
`LoginManager`, `LoginConfiguration`, `FBLoginButton`, permissions, and device login.

Depends on `SwiftBindings.Facebook.Core`.

Built from the official prebuilt `FBSDKLoginKit.xcframework` (dynamic) at upstream v18.1.0.

Targets .NET 10 on iOS.
